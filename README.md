# Rslib Project

## Setup

Install the dependencies:

```bash
yarn install
```

## Get Started

Build the library:

```bash
yarn build
```

Build the library in watch mode:

```bash
yarn dev
```

## dumi使用

```bash
yarn docs:dev
```
启动本地开发服务器，进行项目的开发与调试。

```bash
yarn docs:build
```
构建 dumi 文档产物，适用于生产环境的部署。

```bash
yarn docs:preview
```
在本地启动一个静态 Web 服务器，将 docs-dist 文件夹运行在 http://127.0.0.1:4172, 用于预览构建后产物。
